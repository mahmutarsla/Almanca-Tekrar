Bildiğim kelimeler

A1 kelimelerini (yaklaşık 520: isim, fiil, diğer) ve bütün modal fiilleri bildiğin say. Bunlar yeni kelime olarak sorulmaz, cümle yardımında gösterilmez. Artikelleri bilmediğin için A1 isimlerinin sadece artikeli 2 haftaya yayılarak sorulur; A1 fiillerinin çekimleri (Präteritum, Perfekt) 1 aya yayılarak Fiiller'de gelir.

GitHub'a otomatik kayıt

Anahtarı bir kez girersen cevapların (log/log.csv) ve ilerlemen (log/zustand.json) kendiliğinden repoya yazılır; push gerekmez, telefonda da çalışır. Anahtar sadece bu tarayıcıda saklanır.

Anahtar nasıl alınır?

GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Repository access: Only select repositories → Almanca-Tekrar. Permissions → Repository permissions → Contents: Read and write. Oluşan anahtarı buraya yapıştır.

Log ve yedek (klasör)

Klasörü bağlarsan her cevap log/log.csv dosyasına yazılır, ilerleme de log/zustand.json olarak yedeklenir. Repo klasörünü seç, sonra commit edip pushla. "Sonuçlarıma bak" dediğinde Claude bu dosyayı okur. Chrome ya da Edge gerekir.
